# 支付宝可申购基金 · 四大类 ETF 智能组合回测与下周操作建议（v11）

单文件网站（HTML，ECharts 内联、无外链、可离线打开）：`outputs/final/alipay_fund_4class_v11_<时间戳>.html`

## 一、这一版做了什么

在「支付宝能买到的场外基金」里，筛选四大类 ETF（国债 / 黄金 / A股科技 / 能源），
按**周度调仓、权重取 5% 整数倍**做组合回测，并给出**下周操作建议**（规则权重 + 自主行情判断）。

- **数据源**：东方财富公开接口（`fundmobapi` / `pingzhongdata` / `f10` / 腾讯行情）。
  本次抓取：全市场基金 28,086 只 → 初筛基础池 4,272 只 → 四大类命中 368 只 → 详查 793 只 → 回测用 4 只。
- **筛选标准**：AUM 规模（30 分）+ 认购赎回费（25 分）+ 无认购金额限制（25 分）+ 评价（20 分），
  A股/科创腿另按「年化收益率为核心」的 120 分口径优选。
- **回测规则**：375 组权重（单腿 0/5/…/40%，合计 100%），**每周最后一个交易日**调回目标权重，
  按逐腿真实「优惠申购费 + 持有满 7 天赎回费」扣成本。
- **优化目标**：① 夏普比率进入网格前 10%（本期门槛 1.324，共 38 组）→ ② 在这些解里取年化收益最高者。
- **结论栏**：主推组合的上周 / 近一月 / 近三月 / 今年以来 / 近2年 五个窗口收益，与货基、沪深300 对照。
- **下周操作建议**：规则权重（可复现）+ 自主行情判断（不可复现、可证伪），
  含「为什么这样操作 / 操作方向 / 判断理由来源 / 什么情况会推翻判断 / 下周关键日程」。

## 三、怎么跑

```bash
python run_v11.py          # 一键：网格回测 → 52 周滚动 → 页面数据 → 渲染 → 自检（约 20 秒）
python scripts/verify_v11.py   # 只跑自检
```

> 前置数据（`work/qdii2026/*.json`）已由主流水线抓取。要重新抓基金数据，
> 到上一级流水线目录跑 `python run_weekly.py`（约 2.5 分钟，需东财接口可达）。
>
> bt 引擎交叉验证（第五章）需要 `bt_run/out/` 产物，缺失时先跑：

## 六、已知边界

- 夏普门槛与「门槛内最大化收益」都在同一段历史上算出，**存在后视偏差**，只反映权重敏感度，
  不能当作可复制的收益预期。
- 本页不强制「短窗口必须为正」，因此上周 / 近一月 / 近三月可以为负——这是夏普优先路线的固有代价。
- 不含场内 ETF（支付宝买不到），不含分红逐日现金流模拟（靠复权净值隐含处理）。
- 不构成投资建议，仅供研究。
